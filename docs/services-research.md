## 1. 왜 이렇게 정리했나 (설계 근거)

| 정한 것 | 이유 |
| --- | --- |
| 서비스를 **코드가 아니라 데이터**로 둔다 | 새 서비스는 배열에 **행 하나만 추가**하면 되고 화면 코드는 안 고쳐도 된다. (계획서 5번 대비책) |
| 서비스마다 **요금제 목록**을 갖게 한다 | "넷플릭스 해지하세요"가 아니라 "광고형으로 낮추세요"를 하려면 낮출 요금제가 데이터에 있어야 한다. |
| 요금제마다 **광고·화질·동시접속·오프라인**을 저장한다 | "낮추세요"라고만 하면 뭘 잃는지 알 수 없다. 포기해야 하는 것을 같이 보여 주려면 스펙이 필요하다. |
| 요금은 **웹 결제 · 1인 기준** | 같은 서비스가 결제 수단에 따라 30~40% 비싸진다. 기준을 하나로 통일하고, 실제 결제액은 사용자가 고친다. |
| `strength` / `weakness`를 한 줄씩 | 갈아타기를 추천할 때 "왜 이게 대안인지 / 뭘 포기하는지"를 보여 줘야 한다. |
| **독서·클라우드 카테고리 제외** | 3차에서 뺐다. 클라우드는 '몇 번 썼나'로 판단하는 게 애초에 말이 안 되고(용량이 기준이어야 한다), 독서는 서비스가 하나뿐이라 대체 추천이 불가능했다. |

## 2. 카테고리 분류

갈아타기 추천은 **같은 카테고리 안에서** 찾으므로,
"이걸 끊고 저걸 쓰면 비슷한 일을 할 수 있는가"를 기준으로 나눴다.

| id | 이름 | 설명 |
| --- | --- | --- |
| `ott` | 영상 스트리밍 | 드라마·영화·예능 |
| `music` | 음악 | 음악 스트리밍 (유튜브 포함) |
| `commerce` | 쇼핑·배달 멤버십 | 무료배송·무료배달 혜택 |
| `ai` | AI·생산성 | AI 챗봇 |

> **고민한 점 1**: 유튜브를 `ott`에 넣을지 `music`에 넣을지 애매했다.
> "넷플릭스 대신 유튜브 프리미엄"은 말이 안 되지만 "유튜브 프리미엄 대신 스포티파이"는
> 실제로 많이 하는 고민이라 `music`으로 넣었다. 대체 추천이 말이 되는 쪽을 기준으로 삼았다.

> **고민한 점 2**: 유튜브 프리미엄·라이트·뮤직을 **한 서비스의 요금제 3개**로 묶었다.
> 따로 두면 "프리미엄에서 라이트로 낮추세요"라는 추천이 나올 수 없기 때문이다.

> **고민한 점 3**: 쿠팡플레이는 `ott`와 `commerce`에 걸친다.
> 쿠팡 와우에 포함된 서비스라 요금을 따로 낼 수 없다.
> 둘을 각각 서비스로 두되, **묶음 관계를 따로 표에 적어서** 중복 결제를 잡아내게 했다.

## 4. 조사하면서 찾은 함정 2가지

이 두 가지 때문에 **가격만 보고 "더 싼 요금제로 낮추세요"라고 하면 틀린 추천이 나간다.**

1. **웨이브 베이직(7,900)은 광고형(5,500)보다 비싼데 화질이 720p로 낮고 동시접속도 1대다.**
   "다음으로 싼 요금제"를 기계적으로 고르면 사고가 난다.
   → 그래서 코드에서는 **가장 싼 요금제**와 **광고 없는 것 중 가장 싼 요금제**를 각각 골라서
   둘 다 보여 주고, 바뀌는 스펙을 같이 적는다.

2. **티빙·왓챠 베이직은 동시접속 1대다.** 가족과 나눠 쓰는 사람에겐 "낮추세요"가 틀린 답이다.
   → 요금제를 바꿀 때 동시접속이 줄어들면 반드시 문구로 알려 준다.

## 6. 콘텐츠 규모를 무엇으로 판단할 것인가 (`reach`)

"자주 쓰니 더 좋은 서비스로 갈아타세요"를 판단하려면 콘텐츠 규모 지표가 필요한데,
**각 OTT의 실제 보유 작품 수는 어디에도 공개돼 있지 않다.** 나무위키 OTT 비교 문서도
정성적 서술뿐이었다.

그래서 **주관적인 점수 대신 실제로 측정된 숫자인 국내 월간 이용자 수(MAU)** 를 근거로 삼았다.

| 영상 | MAU (2026.2) | 점수 | 음악 | MAU (2026.1) | 점수 |
| --- | ---: | ---: | --- | ---: | ---: |
| 넷플릭스 | 1,490만 | 5 | 유튜브뮤직 | 980만 | 5 |
| 쿠팡플레이 | 879만 | 4 | 멜론 | 634만 | 4 |
| 티빙 | 552만 | 3 | 스포티파이 | 385만 | 3 |
| 디즈니+ | 295만 | 3 | 플로 | 173만 | 2 |
| 웨이브 | 212만 | 2 | | | |
| 왓챠 | 35만 | 1 | | | |

**한계를 정직하게 적어 둔다.**

- MAU는 **인기**지 콘텐츠 양이 아니다. 왓챠는 독립·예술영화가 강해서 "콘텐츠가 적다"기보다
  **"취향이 다르다"** 가 맞다.
- 그래서 화면 문구도 "콘텐츠가 많은"이 아니라 **"더 폭넓게 쓰이는"** 으로 썼다.
- 쇼핑·AI 카테고리는 MAU 자료를 못 찾아서 `reach`를 비워 두었고,
  **그 카테고리에서는 갈아타기 추천이 아예 나오지 않는다.**
