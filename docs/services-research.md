# 구독 서비스 조사 자료 (차시 1)

조사일: 2026년 9월 9일 · 조사자: 2111 정민재

이 문서는 앱에 넣을 **서비스 목록·카테고리·기본 요금·특징**을 정리한 것이다.
여기 정리한 내용은 그대로 [`src/data/services.ts`](../src/data/services.ts)에 옮겨 두었고,
차시 6~7에서 Supabase `services` 테이블로 옮길 예정이다.

---

## 1. 왜 이렇게 정리했나 (설계 근거)

| 정한 것 | 이유 |
| --- | --- |
| 서비스를 **코드가 아니라 데이터**(배열/테이블)로 둔다 | 계획서 5번의 대비 방법 그대로. 새 서비스가 생기면 **행 하나만 추가**하면 되고 화면 코드는 안 고쳐도 된다. |
| 요금은 **웹 결제 기준 1인 요금** 하나만 저장 | 요금제가 3~4개씩 있는 서비스가 많은데, 전부 넣으면 테이블이 복잡해진다. 사용자는 어차피 구독 등록할 때 **자기가 실제로 내는 금액**을 직접 입력하므로, 여기 값은 **입력창의 기본값(추천값)** 역할만 한다. |
| 서비스마다 `strength`(장점) / `weakness`(단점)를 한 줄씩 저장 | 계획서 3번 스케치의 대체 서비스 추천 화면에서 "왓챠 → 콘텐츠 양이 적음"처럼 **왜 이걸 대신 쓸 만한지 / 뭘 포기해야 하는지**를 보여 줘야 한다. 이 두 줄이 그 자리에 들어간다. |
| iOS 인앱결제 가격은 따로 저장하지 않음 | 같은 서비스가 결제 수단에 따라 30~40% 비싸지는데, 이걸 다 넣으면 요금 비교가 복잡해진다. 웹 결제 기준으로 통일하고, 실제 결제액은 사용자가 수정한다. |

## 2. 카테고리 분류

대체 서비스 추천은 **같은 카테고리 안에서 더 싼 것**을 찾는 방식이므로,
"이걸 끊고 저걸 쓰면 비슷한 일을 할 수 있는가"를 기준으로 6개로 나눴다.

| 카테고리 id | 이름 | 설명 |
| --- | --- | --- |
| `ott` | 영상 스트리밍 | 드라마·영화·예능을 보는 서비스 |
| `music` | 음악 | 음악 스트리밍 (유튜브 프리미엄 포함 — 실제로 음악 용도로 결제하는 사람이 많음) |
| `commerce` | 쇼핑·배달 멤버십 | 무료배송·무료배달 같은 혜택을 사는 멤버십 |
| `cloud` | 클라우드 저장 | 사진·파일 저장 공간 |
| `ai` | AI·생산성 | AI 챗봇, 문서 도구 |
| `book` | 독서 | 전자책·오디오북 |

> **고민한 점**: 유튜브 프리미엄을 `ott`에 넣을지 `music`에 넣을지 애매했다.
> 영상 서비스지만 "넷플릭스 대신 유튜브 프리미엄"은 말이 안 되고,
> "유튜브 프리미엄 대신 스포티파이"는 실제로 많이 하는 고민이라 `music`으로 넣었다.
> 대체 추천이 말이 되는 쪽을 기준으로 삼는 게 맞다고 판단했다.

> **고민한 점 2**: 쿠팡플레이는 `ott`와 `commerce` 양쪽에 걸친다.
> 쿠팡 와우(7,890원)에 포함된 서비스라 요금을 따로 낼 수 없기 때문이다.
> 일단 두 카테고리에 각각 넣되(`coupang-play` / `coupang-wow`),
> 설명에 "와우 멤버십에 포함"이라고 적어 두었다.

## 3. 서비스 목록 (월 요금, 웹 결제 · 1인 기준)

### 영상 스트리밍 (ott)

| 서비스 | 기본 요금 | 장점 | 단점 |
| --- | ---: | --- | --- |
| 넷플릭스 | 13,500원 | 오리지널과 해외 콘텐츠가 가장 많음 | 요금이 비싼 편 |
| 티빙 | 13,500원 | 국내 예능·드라마, KBO 야구 중계 | 해외 콘텐츠가 약함 |
| 웨이브 | 10,900원 | 지상파 실시간 방송과 구작 드라마 | 오리지널 신작이 적음 |
| 디즈니+ | 9,900원 | 마블·픽사·스타워즈 독점 | 전체 콘텐츠 수가 적음 |
| 왓챠 | 7,900원 | 영화 큐레이션이 좋고 요금이 쌈 | 콘텐츠 양이 적음 |
| 쿠팡플레이 | 7,890원 | 와우 멤버십에 포함, 스포츠 중계 | 해외 콘텐츠가 적음 |

**요금제가 여러 개인 서비스** (기본 요금으로 고른 것은 굵게):

- 넷플릭스 — 광고형 5,500 / **스탠다드 13,500** / 프리미엄 17,000
- 티빙 — 광고형 5,500 / 베이직 9,500 / **스탠다드 13,500** / 프리미엄 17,000
- 웨이브 — 광고형 5,500 / 베이직 7,900 / **스탠다드 10,900** / 프리미엄 13,900
- 왓챠 — **베이직 7,900** / 프리미엄 12,900

> 스탠다드를 기본값으로 고른 이유: 광고형은 화질·동시접속 제한이 커서 실제 구독자 비중이 낮고,
> 프리미엄은 보통 가족 계정 공유용이라 1인 기준과 안 맞는다.
> (계획서 스케치에 적은 넷플릭스 17,000원은 프리미엄 요금이다. 기본값은 스탠다드로 두되 사용자가 고칠 수 있게 한다.)
